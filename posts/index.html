  • Agentic Workflow as of October 2026

    Sunday, October 18, 2026

    tl;dr: This post describes my first current very rough approach to agentic development. This approach is heavy on docs, folder structure, and copious tools and scripts for verification feedback. My current approach is codified by the Winetech Standard Repo, which is a barebones skeleton of the structure and built-in agent ready documentation to get started on a new project. Actual Take-Aways Use ADRs Prune memories, AGENTS.md, and other context-filling documents regularly Provide a space to put observations found during their tasks so don’t get distracted and information doesn’t get lost Keep as much inside the repo as possible, to provide agents with the context on demand that they need Provide tools and scripts that can give negative feedback to the agents so they can quickly course-correct on their own Give them a runtime of your application to test against in a live setting. Static analysis is not enough.
